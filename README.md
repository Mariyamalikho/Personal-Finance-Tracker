# Personal Finance Tracker

A responsive web application that helps users track income, expenses, and financial trends through interactive visualizations.

## Features
- User Authentication
- Dashboard
- Transaction Management
- Charts & Analytics
- Local Storage
- Responsive Design

## Technologies
- HTML5
- CSS3
- JavaScript
- Chart.js
- Local Storage API

- Mobile App
- Cloud Sync
- AI Financial Insights
